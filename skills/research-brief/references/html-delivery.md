# 离线报告交付

## 输出组织

把报告放到独立目录，保留 `report.md`、`report.html` 和 `assets/`。证据底稿另存，不自动收进报告或配图包。正文与文件名可用中文；图片内嵌后 HTML 本身可离线显示。用户明确要求引用时，链接到的证据附件再一同保留。原始材料不覆盖。

随附 `assets/report.html` 是独立实现的简洁模板，提供目录、响应式图片和横向滚动表格；仅当输入正文已有摘要或附录时才应用相应样式，不自动新增章节。无远程字体、脚本或图表库。样式可按用户要求调整，不必机械保持固定配色。

## 生成方式

`SKILL_DIR` 指本 skill 的实际安装目录。Python 3.9 及以上；在已有环境或项目虚拟环境中安装 `scripts/requirements.txt`，不要默认改全局环境。

```bash
python -m pip install -r "$SKILL_DIR/scripts/requirements.txt"
python "$SKILL_DIR/scripts/render_report.py" /absolute/output/report.md \
  --output /absolute/output/report.html --meta '项目名 · 阶段研究报告'
```

更新已有 HTML 时加 `--force`；需要打印附录时加 `--expand-appendix`。运行命令后还要打开文件做视觉检查。

Markdown 使用一个一级标题，默认直接从背景或研究问题开始。二级标题形成目录；显式提供 `## 摘要` 时，其后第一段才自动强调。以“附录”或“Appendix”开头的二级章节及其后内容可折叠，附录应放在正文最后。

每张图用独立图片段落，紧接一个以“图 1”或“Figure 1”开头的完整图注段落。示例仅说明格式，不是实际研究结果：

```markdown
![具体发现与图形内容](assets/result.png)

图 1｜有证据支持的发现。写明对象、数量、单位，以及观察和必要的解释范围。
```

工具会把图片与下一段图注组成 figure，内嵌本地 PNG、JPEG、WebP 或 GIF。科学矢量图可保留 SVG 原件，同时导出 PNG 用于嵌入。图片必须有替代文字；缺文件、缺图注或远程图片会明确报错，不自动联网下载。输出与 Markdown 不在同一目录时，本地附件链接会重新计算相对路径。

## 检查范围

生成工具检查一个主标题、图片与图注、本地文件链接及可识别的内部锚点，拒绝正文中的可执行 HTML 和外部嵌入资源。它不核实数字真伪、图注是否充分、远程页面是否可访问，也不替代浏览器检查。

实际打开最终 HTML，检查至少：

- 电脑与窄屏下图片完整加载，标题、图例和表格可读，页面无意外横向溢出；
- 目录链接能定位，附录能展开；图中的字体、坐标轴和标注没有裁切；
- 正文数字与图表一致，独立底稿能追溯到材料；
- 图片内嵌后，报告在离线状态仍可阅读；仅打包正文需要的配图，用户要求引用时再加入必要附件。

浏览器工具不可用时，交付中如实区分“自动检查通过”和“未进行视觉检查”。

## PDF 排版

标题与正文在第一页连续排版，不默认制作封面或摘要页。不要对第一个正文标题强制另起一页；删除章节后检查是否留下空页或孤立段落。

页脚只显示动态的“当前页/总页数”（如 `4/11`），不得写死总页数，不加项目名、报告类型、网址、下载入口或配图包说明。打印时隐藏 HTML 目录控件与操作入口。来源页面、参考文献、来源文件名、制作说明默认不生成；明确要求引用的任务按要求处理。

PDF 导出后重新检查实际页数、页码连续性和全部页面的显示；可编辑 Markdown 与 HTML 同步保留当前正文。
